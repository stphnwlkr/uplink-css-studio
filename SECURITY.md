# Security policy

## Supported version

Security fixes are provided for the latest stable release of Uplink CSS Studio for Bricks.

## Reporting a vulnerability

Please do not publish suspected vulnerabilities in a public issue. Send a private report to the plugin author with the affected version, reproduction steps, impact, and any suggested fix. Reports will be acknowledged after receipt and reviewed before public disclosure.

Do not include credentials, private site data, or personal information that is not needed to reproduce the issue.
